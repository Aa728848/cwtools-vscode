# Agent Note: 发布 v3.4.0（Stellaris 4.6.0 引擎全量对齐与硬编码同步）

Status: implemented

## Problem

自 `v3.3.1` 以来，本仓库与三个子模块完成了围绕 **Stellaris 4.6.0（Corona Borealis）** 反编译源码与原版数据的三阶段全量同步（详录于 [2026-11-28-stellaris-4.6-engine-decompilation-audit-and-sync.md](2026-11-28-stellaris-4.6-engine-decompilation-audit-and-sync.md)），涵盖 CWT 规则、性能与反模式校验器、索敌计算模型与预览面板、数据流分析、核心回退常量、引擎文档与技能。需要按发布 SOP 同步版本号、双语更新日志、单源文档并完成全平台打包与标签推送，由 `.github/workflows/release.yml` 自动发布至 VS Code Marketplace 与 GitHub Releases。

## Decision

- **版本号升级 `3.3.1` → `3.4.0`（Minor）**：本次包含大量面向用户的新增规则/校验能力（52 条 4.6 Ideology 命令、15 条 `sync_effect = pop_jobs`、`CW279`/`CW281`/`CW284`/`CW286`/`CW287`/`CW288`/`CW290`/`CW120` 扩展、索敌 `target_focus` 联动及三处计算模型纠偏、21 种事件链扫描与 `calc_true_if` 推断等），符合 SemVer 次版本升级标准。同步更新 `package.json` 与 `release/package.json`。
- **子模块先行推送纪律**：在打标发版前，三个子模块均已完成独立提交并推送至各自远程默认分支，保证云端 Release CI `checkout (submodules: recursive)` 可确定性拉取：
  - `submodules/cwtools`：`621f0d92` (`master -> origin/master`)
  - `submodules/cwtools-stellaris-config`：`81e43d5` (`master -> origin/master`)
  - `submodules/cwtools-mcp`：`27dbc8a` (`main -> origin/main`)
- **内置共享包打包方式**：`release/package.json` 保持 `cwtools-shared@0.7.0` / `cwtools-node@0.4.2` 运行时依赖锁定，由 `package.ps1` 在打包阶段将 `submodules/cwtools-mcp` 最新构建出的 `dist/` 覆写进 `release/node_modules/`，确保 VSIX 内置最新 `targetingWeights` 与 `targetWeightExtract` 逻辑且 `vsce` 依赖闭包校验通过。

## Alternatives considered

- **发 Patch 版本 `3.3.2`**：否决。本次不仅包含缺陷修复，还包含面向 Stellaris 4.6.0 的全套规则、校验器、索敌预览联动与引擎分析能力扩展，次版本 `3.4.0` 更准确传达变更量级。
- **跳过本地 `package.ps1` 直接推标签依赖 CI**：否决。按 `release-extension` 技能要求，先在本地完成 `build:docs`、`verify` 与 `package.ps1` 三平台自包含打包预检，提前排除发布构型下的 `.NET` / `vsce` 风险。

## Consequences

- 推送 `main` 与 `v3.4.0` 标签后，`.github/workflows/release.yml` 自动在 `windows-latest` 上构建通用 VSIX、通过 OIDC Trusted Publishing 发布至 VS Code Marketplace，并从 `release/CHANGELOG.md` 的 `[3.4.0]` 区块生成 GitHub Release。
- 本次未单独向 npmjs 发布 `cwtools-shared` / `cwtools-node` / `cwtools-mcp` 新版本；VS Code 扩展通过 `package.ps1` 内置了最新构建的共享包。后续若需同步独立 MCP CLI / DSH 插件至 npm，可在 `submodules/cwtools-mcp` 单独发版并更新 `release/package.json`。
- 验证门禁全部通过：`npm run build:docs`、`npm run verify`（`eslint` 0 errors + `compile` + `typecheck:test` + `test:unit` 912+60+7 passing + `check:release`）、`npm run test:fsx`（36/36 passed）、`package.ps1` 全三平台自包含打包产出 `release/foreverskywalker-stellaris-cwtools-3.4.0.vsix`（2032 files, 148.26 MB），以及打包后 `npm run check:release -- --skip-compile --skip-test` 全绿。
