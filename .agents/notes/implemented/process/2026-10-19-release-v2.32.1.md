# Agent Note: 发布 v2.32.1

Status: implemented

## 背景

在 v2.32.0 发布后，用户在会话中要求「总结本次回答和模型组合有关的经验，做成模型skill」时，因 `save_skill` 未归入 `file_write` 披露组且未在提示词中声明，加之 `.cwtools` 别名把查询重定向到 `workspaceStorage` 私有目录，模型退而使用通用写工具修改 `experience.json` 并触发 `outside the writable roots`（`policy_denied`）直接终止整轮对话。

## 版本决策

- 本次发布包含 `save_skill` 自动披露、Profile 白名单补齐、`.cwtools` 共享路径解析修复以及误写技能/经验路径时的可恢复重定向修复（及 `c97c6201` 规则指纹记录）→ 按 SemVer 定为**补丁版本 2.32.1**（2026-10-19）。
- 设计决策已就地同步至 Owning Note（`feature/2026-10-13-save-skill-tool.md`），本篇记录发布流程。

## 交付影响

- 用户侧：在对话中要求总结经验并保存为 Agent Skill 时，模型可直接调用 `save_skill` 完成保存，即使误调通用写工具也会收到非终止的 `save_skill` 引导而不会因目录限制中断整轮回答。
- 包体：全平台 universal VSIX（win-x64 ReadyToRun / linux-x64 / osx-x64 自包含服务端）。

## 验证契约

- `npm run check:release -- --skip-compile --skip-test` 通过（两处 package.json 版本一致、NLS 同步、changelog 条目存在）。
- GitHub Release `v2.32.1` 挂载 universal VSIX，发布说明取自 CHANGELOG 对应区块。
