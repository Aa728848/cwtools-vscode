# Agent Note: Release v2.18.0 for Multi-root Workspace Support, CommandCode Provider, and Repetition Recovery

Status: implemented

## Problem
自 `v2.17.1` 发布以来，仓库合入了多项重大特性演进与底层关键缺陷修复：
1. **多根工作区架构适配**：解决了多工作区环境下 AI 根目录固定导致跨工作区路径误判越界、沙箱校验误拒以及制品隔离缺失问题；
2. **CommandCode 供应商接入与额度监控**：实现了 `commandcode` 与 `commandcode-messages` 双接入协议，并在设置界面上线了实时用量进度条与账户配额可视化卡片；
3. **推理死循环与重复自愈机制**：新增 `OutputRepetitionRecovery` 与 `RecoveryCoordinator`，在模型出现僵化重复时通过降级思考（Low Thinking）与定向引导自动打破死循环；
4. **模型目录与默认配置升级**：默认推荐模型升级为 `gpt-6-astra`，Codex 订阅渠道开放 1M 超大上下文支持，DeepSeek 目录刷新并引入 `deepseek-flash` 及其峰谷计费；
5. **实体 3D 预览定位器旋转修正**：消除了 `pdxScriptEuler` 冗余的 180° 取反补偿，解决了特效挂接朝向反转缺陷；
6. **CW226 本地化事件目标作用域修复**：同步 cwtools 核心引擎修复了事件目标校验问题；
7. **全仓 LF 换行符与 EditorConfig 规范化**。

为了向用户完整交付上述功能并保持语义化版本规范，需要将扩展升级为次版本 `2.18.0`，编写更新日志，重新构建通用 VSIX 安装包并发布到 GitHub Release。

## Decision
1. **版本提升**：
   将根目录 `package.json` 与 `release/package.json` 中的 `version` 统一升级为 `2.18.0`。
2. **变更日志记录**：
   在 `release/CHANGELOG.md` 中新增 `## [2.18.0] - 2026-09-16`，双语详尽记录多根工作区适配、CommandCode 供应商与配额可视化、推理重复自愈、模型目录升级（GPT-6 Astra / Codex 1M / DeepSeek Flash）、实体定位器旋转修复、本地化 CW226 修复及 LF 规范化。
3. **单源文档生成与质量验证**：
   运行 `npm run build:docs` 同步生成 release 对应 README，运行 `npm run check:release` 确保各项门禁检查通过。
4. **编译、打包与 GitHub Release 发布**：
   通过流水线构建跨平台自包含 F# 语言服务器（win-x64、linux-x64、osx-x64）、编译 TypeScript 客户端与 Rollup Webview 前端，打包生成通用 VSIX，并由 GitHub CLI 创建 Tag `v2.18.0` 及对应 GitHub Release。

## Alternatives considered
- **升级为 2.17.2 补丁版本**：
  不采纳。本次不仅包含 Bug 修复，更包含了“多根工作区支持”、“CommandCode 供应商接入与额度监控”、“推理死循环自愈”等重磅架构与新功能扩展，按照 SemVer 语义化版本规范，必须提升次版本号（Minor Version）。
- **仅更新本地代码不发布 Release 资产**：
  不采纳。用户通过 VS Code 扩展市场或 GitHub Releases 获取离线 VSIX 包，必须生成完整打包资产并同步推送。

## Consequences
- 发布 `v2.18.0` 扩展包，全面覆盖三平台自包含语言服务器运行环境。
- 用户可在多根工作区下顺畅使用 AI 编码辅助，在设置面板中直观掌握 CommandCode 与 Codex 配额用量，并在 3D 预览中获得完全准确的模型挂接效果。
