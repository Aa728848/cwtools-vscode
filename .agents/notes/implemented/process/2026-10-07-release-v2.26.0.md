# Agent Note: Release v2.26.0 for Steam Workshop Upload & CWTools Core Updates

Status: implemented

## Problem

自 `v2.25.0`（2026-10-06）发布以来，仓库包含 4 次提交：
1. `cd7bcca4 docs: record the v2.25.0 release decision note`
2. `dc6b076a chore(cwtools): bump submodule to fix release SDK drift and LF fixture parsing`
3. `75781618 chore(cwtools): bump submodule for CLI list/parse fixes and fork metadata alignment`
4. `cd233f1d 更新推送`（包含完整的 Steam 创意工坊 Mod 扩展内上传面板与核心实现）

核心问题与需求驱动：
1. **Mod 创作者工坊发布链路缺失**：此前扩展仅具备工坊路径检测能力，用户要在 Steam 创意工坊上新建 Mod 或更新已有 Mod，必须退出编辑器并在 Paradox 官方启动器或外部 CLI 工具中繁琐操作。
2. **底层 CWTools CLI 子命令不可用与输出管道异常**：上游/子模块中 `parse` 子命令此前未实际接线到 `CKParser`；`list` 子命令的输出无法被外部调用端有效观测。
3. **CI 流水线 SDK 漂移**：子模块发布流水线曾停留在 .NET 9.0，而工程已面向 .NET 10.0，且 LF 换行下的测试 fixture 解析存在兼容隐患。

由于引入了面向用户的重磅新功能（Steam 创意工坊上传专属面板与全链路支持），依据 SemVer 规范应升级次版本（Minor Release）。

## Decision

1. **版本号升级（Minor）**：
   - 根目录 `package.json` 与 `release/package.json` 统一升级至 `2.26.0`。
2. **更新日志编写**：
   - 在 `release/CHANGELOG.md` 顶部按中英双语格式追加 `## [2.26.0] - 2026-10-07` 区块，详尽阐述 Steam 创意工坊 Mod 上传与底层 CWTools 引擎/CLI 的改进。
3. **流程决策归档**：
   - 编写并归档本 Note `.agents/notes/implemented/process/2026-10-07-release-v2.26.0.md`。
4. **单源文档与门禁验证**：
   - 运行 `npm run build:docs` 同步生成双语 README 与 release 目录说明文件。
   - 运行 `npm run compile` 编译 TypeScript 与打包 Webview 资源。
   - 运行 `npm run check:release -- --skip-compile --skip-test` 执行发布门禁全项核验。
5. **Universal VSIX 打包与发布**：
   - 运行 `./package.ps1`，打包全平台（win-x64、linux-x64、osx-x64）自包含 .NET 语言服务器与 Node-API steamworks.js 原生扩展。
   - 创建 Git 提交、添加版本标签 `v2.26.0`、推送分支与标签至 GitHub，并通过 GitHub CLI 发布 Release 挂载 `.vsix` 文件。

## Alternatives considered

- **升级为 Patch 版本（2.25.1）**：不采纳。本次包含 Steam 创意工坊直传面板（独立侧边栏视图、命令交互、Descriptor 自动回写、原生 SDK 集成）这一完整的新增功能特性，按 SemVer 必须为次版本。
- **拆分 Steam 上传为独立插件**：不采纳。Paradox Mod 创作者的核心痛点之一就是开发、代码诊断与发布断层，整合至 CWTools 可最大化发挥工程上下文与 descriptor 语义理解的协同优势。
- **仅打包 Windows 平台**：不采纳。扩展维持 Universal VSIX 分发形态，各平台语言服务器自包含，`steamworks.js` 也自带跨平台预编译二进制。

## Consequences

- 交付 `v2.26.0` 通用扩展包，Mod 创作者可在 VS Code 内部直接完成 Stellaris 等 Paradox 游戏 Mod 的工坊创建与更新。
- 保证扩展在无 Steam 运行环境下的优雅降级，按需动态加载原生模块，不影响扩展激活性能。
- 修复并验证了底层 cwtools CLI 工具链及跨平台测试与构建流程。
- 遵循版本唯一定义源规范，文档与注释不重复版本数字。
