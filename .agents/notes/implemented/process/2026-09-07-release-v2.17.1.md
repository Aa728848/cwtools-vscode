# Agent Note: Release v2.17.1 for Plan Approval Card Display and Dismiss Race Fix

Status: implemented

## Problem
在 `v2.17.0` 发布后，用户反馈计划审批卡在对话界面中无法正常弹出显示，且在独立管理器界面右侧也无法正确呈现。经深度排查，发现前端在接收计划渲染消息时调用了带有异步延时的 `dismissCard`，导致刚挂载的新卡片在 260ms 后被定时器错误销毁；同时服务端计划文件检索未覆盖标准话题目录，且独立界面在纯卡片场景下未自动导向审查面板。为向用户交付该关键修复，需要将版本提升至 `2.17.1`，记录更新日志，打包通用 VSIX 插件包并发布至 GitHub Release。

## Decision
1. **版本提升**：
   将 `package.json` 与 `release/package.json` 的版本号从 `2.17.0` 升级为 `2.17.1`，遵循语义化补丁版本规范。
2. **变更日志记录**：
   在 `release/CHANGELOG.md` 中增加 `## [2.17.1] - 2026-09-07` 中英文条目，详细说明异步销毁竞态消除、复用样式恢复、双目录检索与独立界面联动修复。
3. **单源文档与质量核验**：
   执行 `npm run build:docs` 同步文档，执行编译与回归测试套件。
4. **打包与 GitHub Release 发布**：
   通过打包管道构建 win-x64、linux-x64、osx-x64 三平台自包含语言服务器及前端资产，生成通用 VSIX 包，完成 Git Commit、Tag `v2.17.1`、推送主干与 Tag，并通过 `gh release create` 上传发布。

## Alternatives considered
- **不提升版本直接就地修复**：不可行，用户需要明确的版本号与 Releases 资产来完成更新与部署。
- **发布预发布版本（Pre-release）**：该修复属于高优先级的缺陷修复，且经 2388 项单元测试与烟雾测试验证无回归，直接发布正式补丁版本最为适宜。

## Consequences
- 成功发布 `v2.17.1` 扩展包，修复了计划审批卡在对话界面与独立界面的弹出与展示问题。
- GitHub Release 资产已同步更新。
