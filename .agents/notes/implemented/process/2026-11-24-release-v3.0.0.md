# Agent Note: Release v3.0.0 —— 移除内置 Agent 并发布统一 MCP/DSH 宿主

Status: implemented

## Problem

内置 Chat、Agent Manager、Runner、Provider/号池、行内 AI 补全和 MCP Client 已被外部 Agent 与统一领域工具宿主取代。该迁移删除用户可见功能，需要以明确的大版本、双语更新日志和同步的 npm 依赖交付，而不是继续作为 2.x 的兼容更新。

## Decision

- 根扩展发布 `3.0.0`；`cwtools-shared@0.4.0`、`cwtools-node@0.3.0`、`cwtools-mcp@0.5.0` 与 `dsh-cwtools@0.3.0` 按依赖顺序发布，根仓库推进到对应发布提交。
- 更新根与 `release/` 的版本和锁文件，并将 VSIX 运行时依赖同步到 `cwtools-node@0.3.0`、`cwtools-shared@0.4.0`，保持 VSCE 的真实依赖闭包检查。
- 采用现有标签 CI 进行 Marketplace Trusted Publishing 与 GitHub Release，不使用本地 `package.ps1 -Publish`。
- 不实施会话中动态工具增删；Code Mode 继续使用固定 native 白名单与 `code_tools_search/describe`，避免破坏前缀缓存和调度兼容。

## Alternatives considered

- `2.40.0`：不采纳。本次物理删除内置 Agent 用户功能，属于破坏性升级。
- 在 MCP 层新增 `select_tools` 和 `tools/list_changed`：不采纳。Code Mode 已有按需 schema 发现，动态工具表会给缓存敏感线路和旧代宿主增加不必要风险。
- 跳过依赖版本同步或绕过 VSCE `npm list`：不采纳。发布包必须安装与清单一致的真实依赖。

## Verification

- MCP：三包构建、全部契约测试、npm pack 干跑与 `git diff --check` 通过；registry 已可见 `cwtools-shared@0.4.0`、`cwtools-node@0.3.0`、`cwtools-mcp@0.5.0`。
- DSH：完整测试、typecheck/build、npm pack 干跑通过，`dsh-cwtools@0.3.0` 已执行发布。
- 根仓库：`build:docs`、`compile`、`typecheck:test`、`test:unit`、`check:release` 与 `git diff --check` 通过。
- 完整 `package.ps1` 已成功构建 win-x64、linux-x64、osx-x64 自包含服务器；修正发布依赖后以 `-SkipServer` 复用这些服务器完成 VSIX，`foreverskywalker-stellaris-cwtools-3.0.0.vsix` 为 147.72 MB、1959 文件。
