# Agent Note: Release v2.22.0 for Aura Localisation Generator and Virtual Buffer Refresh Fix

Status: implemented

## Problem
自 `v2.21.0` 发布以来，项目补齐了光环（aura）脚本与本地化之间的最后一环，并修复了一个影响所有只读虚拟文档的既有缺陷：

1. **光环本地化只能手工编写**：`common/component_templates/*.txt` 的 `friendly_aura` / `hostile_aura` 需要一条自定义 Tooltip 本地化；作者此前只能手工把 `modifier` 里的每条修正抄成 `$MOD_XXX$：§G+50%§!`，键名大小写、正负号、百分比换算、`damage_per_day` 数值与换行转义都容易出错，光环一多则难以保持一致。既有的 `genlocfile` / `genlocall` 只处理"缺失本地化键"（CW100），无法从光环定义推导 Tooltip 内容。
2. **只读虚拟文档连续更新会被丢弃**：`createVirtualFile` 通知处理器按"打开文档 → 直接 applyEdit"更新 `cwtools://` 缓冲区，连续生成时会被 VS Code 以 `has changed in the meantime` 忽略，缓冲区停留在上一次内容。
3. **内置规则包更新**：同窗口内刷新了 `release/rules/stellaris-rules.zip`。

为交付上述新能力与修复，依据 SemVer（新增面向用户的功能 + 行为修复，非纯补丁）需将扩展升级为次版本 `2.22.0`，编写中英双语更新日志，编译三平台自包含语言服务器并打包通用 VSIX 上传 GitHub Release。

## Decision
1. **版本号升级（Minor）**：
   将根目录 `package.json` 与 `release/package.json` 的 `version` 统一升级为 `2.22.0`。
2. **更新日志编写**：
   在 `release/CHANGELOG.md` 顶部新增 `## [2.22.0] - 2026-09-23` 区块，按既有中英双语格式记录光环本地化生成器（特性）、虚拟缓冲区更新修复（修复）与内置规则包刷新（维护）。
3. **单源文档与门禁**：
   运行 `npm run build:docs` 同步 `release/README.md`，运行 `npm run compile` 与 `npm run check:release -- --skip-compile --skip-test` 验证版本一致性、NLS 完整性与文档单源约束。
4. **跨平台通用 VSIX 打包**：
   执行根目录 `package.ps1`，依次发布 win-x64（ReadyToRun）、linux-x64、osx-x64 自包含 F# 语言服务器，编译 TypeScript 客户端与 Rollup Webview，最终由 `@vscode/vsce` 输出单一通用 `.vsix`。
5. **Git 与 GitHub 发布**：
   提交版本与日志变更，打 `v2.22.0` 标签，推送分支与标签，并通过 GitHub CLI 创建 Release 并挂载 VSIX 产物。

## Alternatives considered
- **升级为 2.21.1 补丁版本**：
  不采纳。本次新增了面向用户的光环本地化生成能力（新命令、新入口、新输出契约）与新的测试覆盖，属于向下兼容的新特性，按 SemVer 应升级次版本。
- **只提交代码、跳过打包与 Release**：
  不采纳。用户明确要求按 `release-extension/SKILL.md` 走完整发布闭环，需要产出三平台自包含 VSIX 并上传 Release。
- **把生成结果直接写入本地化 `.yml`**：
  不采纳（功能设计阶段已评估）。直接落盘需要复用 `write_localisation` 的多语言事务、BOM/表头与写队列，并为命令引入写权限与回滚语义；当前以只读虚拟文档交付更小切口，用户可自行核对粘贴，相关权衡记录在 `.agents/notes/implemented/feature/2026-09-23-aura-localisation-generator.md`。

## Consequences
- 发布 `v2.22.0` 通用扩展包，覆盖 Windows / Linux / macOS 自包含运行环境。
- 模组作者可以把光环的 `modifier` 与 `damage_per_day` 一键转换为本地化文本，并在编辑器内核对后再粘贴；只读虚拟缓冲区（含 `Generate missing loc`、`List all …`）的连续更新不再丢失。
- 版本号仅由根 `package.json` 与 `release/package.json` 承载，文档与注释不重复数字，遵循既有约定。
