# Agent Note: 发布 v2.31.0

Status: implemented

## 背景

自 v2.30.0（2026-10-14）以来共 5 个提交，全部围绕 Stellaris 4.5.2 舰船索敌权重工具链：
知识/规则层（设计文档、CWT 规则、Agent 技能）、工具层（纯计算模块、`query_targeting_weight`、
分析面板 Webview）、LSP 新诊断 CW290，以及三轮实机面板迭代（CSV 数值合并、真实船型下拉、
ComboBox 与 inline_script 字段级展开）。含新命令、新工具、新诊断，按 SemVer 定为**次版本 2.31.0**（2026-10-15）。

## 版本决策

- 新面板命令 + 新 AI/MCP 工具 + 新诊断码 → minor 而非 patch。
- cwtools-mcp 0.2.8 先行发布 npm（cwtools-shared 0.2.8 同步），子模块提交 `50d6ed7`，根仓指针在 `b1c1e188`。
- 设计决策归属：索敌权重工具链 Owning Note 为
  [2026-10-13-targeting-weight-tooling.md](../feature/2026-10-13-targeting-weight-tooling.md)，
  知识与规则决策见 [2026-10-13-stellaris-targeting-weight-knowledge-rules.md](../feature/2026-10-13-stellaris-targeting-weight-knowledge-rules.md)；本篇只记录发布流程。

## 交付影响

- 用户侧：索敌权重分析面板（中英双语、逐因子可视化）、CW290 范围告警、`query_targeting_weight`
  在 Agent 与 MCP 两侧可用；全参数化 mod（inline_script 拼装数值）的武器也能被面板扫描分析。
- 包体：全平台 universal VSIX（win-x64 ReadyToRun / linux-x64 / osx-x64 自包含服务端）。
- 外部 Agent：`npx -y cwtools-mcp` 拉到的 0.2.8 含索敌权重工具。

## 验证契约

- `npm run build:docs`、`npm run compile`、`npm run check:release -- --skip-compile --skip-test` 通过。
- GitHub Release `v2.31.0` 挂载 universal VSIX，发布说明取自 CHANGELOG 对应区块。
- npm registry：`cwtools-mcp@0.2.8` / `cwtools-shared@0.2.8` 为 latest。
