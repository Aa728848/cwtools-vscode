# Agent Note: 发布 v2.34.0

Status: implemented

## 背景

v2.33.0 之后主分支只有一个提交 `9b6b704c`（feat(ai): refresh Kimi K3.1 provider routes）：把 Kimi 的两条线路
（开放平台 `kimi` 与订阅 `kimi-code-plan`）默认模型迁到 K3.1，随包目录改为逐模型窗口与能力，实时目录真正
驱动模型选择，并统一了 `max_completion_tokens`、usage、reasoning 回写与 K2.5 读取期迁移。用户要求发版。

## 版本决策

- 该提交带来用户可见变化（默认模型、可选模型清单、思考档位、请求协议、价格展示），属新特性而非纯修复，
  按 SemVer 定为**次版本 2.34.0**（2026-10-27）。
- 本次改动本身的设计决策与取舍记录在 Owning Note
  [feature/2026-10-26-kimi-k3-1-dual-line-refresh.md](../feature/2026-10-26-kimi-k3-1-dual-line-refresh.md)，
  本篇只记录发布流程，不重复其中事实。

## 交付影响

- 用户侧：新配置与未显式选型的用户默认进入 K3.1 Pro；已下线的 `kimi-k2.5` 不再出现在 `kimi` 线路内置
  选项里，磁盘上的旧配置在读取有效配置时于内存中落到继任模型，不擅自改写用户文件。设置页、快捷档位与
  请求装配共用同一份目录解析结果，目录不可读时安全回退静态能力。
- 包体：全平台 universal VSIX（win-x64 ReadyToRun / linux-x64 / osx-x64 自包含服务端）。

## 验证契约

- `npm run build:docs`、`npm run compile`、`npm run check:release -- --skip-compile --skip-test` 均通过
  （两处 `package.json` 版本一致、NLS 同步、changelog 条目存在）。
- `package.ps1` 依次完成三平台自包含服务端构建并产出单一 universal VSIX。
- GitHub Release `v2.34.0` 挂载该 VSIX，发布说明取自 `release/CHANGELOG.md` 的 2.34.0 区块。
