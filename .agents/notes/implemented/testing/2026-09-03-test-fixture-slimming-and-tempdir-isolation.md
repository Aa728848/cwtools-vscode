# Agent Note: Test Fixture Slimming and Tempdir Isolation

Status: implemented

## Problem
在测试运行与资产管理中，存在以下阻碍测试效率与稳定性的问题：
1. **测试夹具过于庞大**：测试用的材质资源（如 `faction_room.dds`）体积高达 1.7MB，不仅占用仓库空间，还延长了测试加载与发布打包时间。
2. **重复冗余的测试用例文件**：样例 Mod 目录中包含了 5 个结构完全相同的同构本地化 YAML 夹具，无实际差异化断言价值。
3. **临时工作区污染开发目录**：部分测试直接在源码树或特定子目录创建临时测试文件，测试失败或异常中断时遗留脏文件。
4. **测试桩碎片化**：Runner 和断点恢复（Resume）测试各自维护独立的 Mock 桩与重复夹具。

## Decision
1. **精简二进制材质夹具**：
   - 将 `faction_room.dds` 重新构建为体积仅 1.1KB 的微型合法 DDS Stub，保留正确的 DDS 魔数、格式标头与最小尺寸像素阵列，确保图形解析器校验通过的同时将体积缩减 99.9%。
2. **修剪同构冗余夹具**：
   - 剔除 5 份重复的本地化文件，仅保留最小完备断言用例。
3. **隔离临时目录至系统临时空间**：
   - 统一重定向所有测试的临时目录路径至操作系统的标准 `os.tmpdir()`，确保用例间相互隔离，执行结束后自动或受控释放。
4. **合并收拢测试微套件**：
   - 整合 Runner 与 Resume 的测试基础设施，统一导出与配置状态覆盖（`setStubConfigOverrides`）。

## Alternatives considered
- **使用 0 字节空文件替代 DDS 贴图**：
  - *未采纳原因*：后端图形解析器在读取 DDS 时会严格校验文件头魔数与图像描述符，空文件会触发格式解析失败；定制合法的微型 DDS 既满足协议校验又大幅压缩了体积。
- **保留本地临时目录并在 Git 忽略列表过滤**：
  - *未采纳原因*：跨平台 CI 环境下可能存在不同盘符或权限限制，且容易产生意外残留；`os.tmpdir()` 具备原生平台支持与沙盒隔离。

## Consequences
- 测试资源体积大幅缩减，仓库更加轻巧。
- 消除了本地测试运行对工作区的隐蔽污染，跨平台（Win/Linux/macOS）CI 稳定性提升。
