# Agent Note: 发布 v3.2.0 与 v3.3.0 重打包

Status: implemented

## Problem

v3.1.0 之后的一批改动把 VS Code 扩展里重复的编辑器解析器收敛到共享包，并新增了三个领域写入工具与 DSH 原生工作台。这些改动分散在四个仓库（`cwtools`、`cwtools-mcp`、`dsh-cwtool`、本仓），且 `cwtools-shared` 新增的 `./editors` 子路径导出此前从未发布到 npm——已发布的 `0.5.0` 只导出 `.` 与 `./catalog`，而 `cwtools-node` 源码已硬依赖 `cwtools-shared/editors`，按旧版本号从 registry 安装必然解析失败。

## Decision

- 版本号：本仓 `3.1.0` → `3.2.0`（minor）。理由是跨模块契约变化加新工具，不是纯修复；`release/package.json` 与根 `package.json` 同步。
- `cwtools-mcp` 三包按依赖顺序发布：`cwtools-shared` 0.5.0 → 0.6.0、`cwtools-node` 0.3.1 → 0.4.1、`cwtools-mcp` 0.5.1 → 0.6.1。node 与 mcp 的依赖同步钉到 `cwtools-shared 0.6.0`。
- `dsh-cwtool` 0.3.1 → 0.3.3，依赖同步钉到 `cwtools-shared 0.6.0` / `cwtools-node 0.4.1`，并在 `pnpm-workspace.yaml` 的 `minimumReleaseAgeExclude` 里登记新版本，避免 pnpm 因最小发布年龄拒绝解析。
- `release/package.json` 的运行时依赖闭包此前仍钉 `cwtools-shared 0.4.0` / `cwtools-node 0.3.0`，本次一并更新到 `0.6.0` / `0.4.1`，使锁文件与 `package.ps1` 暂存的本地构建一致。
- `submodules/cwtools` 不发版：`src/Main/Main.fsproj` 以 `ProjectReference` 直接编译其源码，没有独立分发通道。

## Consequences

- 3.2.0 首次 CI 已把 148MB VSIX 与 GitHub Release 发出去，但该包内置 `cwtools-node 0.4.0`；随后 npm 上 `0.4.1` 成为 latest，为让「内置版本 = npm latest」一致，另发 3.3.0 重打包（功能与 3.2.0 完全相同，只换内置依赖版本）。3.3.0 是最终对外版本。
- 3.2.0 与 3.3.0 之间只差 `release/package.json` 的 `cwtools-node` 版本与重新构建的服务端；不需要再动 npm 包。

- npm 上四个包的实际生效版本为 `cwtools-shared@0.6.0`、`cwtools-node@0.4.1`、`cwtools-mcp@0.6.1`、`dsh-cwtools@0.3.3`；`cwtools-shared@0.6.0` 的 exports 含 `./editors`，`cwtools-node@0.4.1` 含 `dist/hosts/shipDesignResources.js` 等新模块。`cwtools-node@0.4.0`/`cwtools-mcp@0.6.0`/`dsh-cwtools@0.3.2` 与它们的 `0.4.1`/`0.6.1`/`0.3.3` 内容一致，仅版本号不同。
- 发布过程中确认 npm 可能异步落库（本次延迟可达十余分钟）：`npm publish` 回显成功后 packument 需要数分钟才更新，期间 `npm view <pkg>@<ver>` 与 `curl /pkg/<ver>` 都会返回 404，且再次 `npm publish` 会报 `E409 Cannot publish over previously staged version`。**不要在 404 时立即换版本号重发**——应先等待并用 packument 的 `versions` 列表确认。本次曾误判为未落地而先回退、随后发现 `0.4.1`/`0.6.1`/`0.3.3` 实际已落库为 latest，遂重新提交恢复；这两轮往返留下了成对的 revert 与 restore 提交。
- 验证：`cwtools-mcp` 的 `npm run build` 与 `npm run test:contracts`（24 passing）通过；`dsh-cwtool` 的 `pnpm run build`（含 typecheck、tsdown、单模块 bundle 校验）与 `pnpm test`（18 文件 140 项）通过；本仓 `npm run build:docs` 与 `npm run check:release -- --skip-compile --skip-test` 通过。
- 遗留：`release/CHANGELOG.md` 只追加 3.2.0 区块，历史条目未刷新；扩展侧 `docs/p4-validation.md` 仍是历史文档。
