# Agent Note: Release v2.17.0 with Antigravity Support and Shared Proxy

Status: implemented

## Problem
自 `v2.16.9` 以来，仓库合入了多项关键特性与重大改进：
1. 原生 Antigravity AI 提供商集成、OAuth 回调鉴权、以及专属 Tab 智能代码补全与光标跳转机制；
2. 订阅提供商共享代理（SOCKS5 / HTTP / HTTPS）支持，增强了受限网络环境下的连接弹性；
3. 全新的 AI 对话面板架构与多话题（Topic Views）视图管理；
4. 图形纹理文件变动时图片悬停预览的缓存失效与废弃临时文件清理修复。

为了向用户交付上述能力，需要将插件版本升迁至 `2.17.0`，编写详尽的双语变更日志，同步发布文档，构建多平台自包含通用 VSIX 插件包，并发布到 GitHub Release。

## Decision
1. **版本提升**：
   将 `package.json` 与 `release/package.json` 的版本号从 `2.16.9` 升级为 `2.17.0`，遵循语义化版本规范。
2. **变更日志记录**：
   在 `release/CHANGELOG.md` 中增加 `## [2.17.0] - 2026-09-06` 详细中英文条目，覆盖 AI 提供商扩展、Tab 代码补全、网络代理、会话面板重构与图形缓存失效修复四大模块。
3. **单源文档构建与质量准入验证**：
   执行 `npm run build:docs` 更新 release README，运行 `npm run check:release` 确保无缺失字段或协议冲突。
4. **自动化打包与 GitHub 发布**：
   通过 `package.ps1 -Publish` 编译三平台自包含语言服务器及前端资产，生成通用 VSIX 包，并自动化完成 Git Commit、Tag `v2.17.0`、推送以及 `gh release create` 上传。

## Alternatives considered
- **升级为 2.16.10**：
  鉴于本次包含了全新的 AI 提供商（Antigravity）、Tab 补全服务、共享网络代理与对话面板重构等重量级特性，而非单纯的小修小补，跳过次版本号升迁违背语义化版本规范，故采纳 `2.17.0`。
- **纯手工分步执行打包和 release 命令**：
  易造成各平台二进制构建参数脱节或忘记构建单源文档；统一依赖经过验证的 `package.ps1` 自动化管道能确保各环节幂等一致。

## Consequences
- 成功发布 `v2.17.0` 扩展包，终端用户可在 VS Code 中获取最新的 Antigravity 模型支持、Tab 补全能力与订阅代理配置。
- 保证了版本号、单源文档、更新日志及 GitHub Release 资产的严格同步。
