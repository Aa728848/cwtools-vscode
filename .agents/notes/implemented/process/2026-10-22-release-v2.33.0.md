# Agent Note: 发布 v2.33.0

Status: implemented

## 背景

v2.32.1 之后合并了两项改动：一项是 WorkBuddy / OpenCode Go 线路下线（已在 `[Unreleased]` 中登记），另一项是从舰船模型生成舰船顶部图标表的新功能（提交 `56263a90`）。用户要求把这个功能正式发版。

## 版本决策

- 新增用户可见命令、设置项、工具栏入口与一整套解析/渲染管线 → 按 SemVer 定为**次版本 2.33.0**（2026-10-22）。
- 功能的设计决策与取舍记录在 Owning Note [feature/2026-10-22-ship-icon-sheet-from-models.md](../feature/2026-10-22-ship-icon-sheet-from-models.md)，本篇只记录发布流程。

## 交付影响

- 用户侧：Mod 工作区可在命令面板或编辑区右上角运行「从模型生成舰船顶部图标表」，按图形文化 + `class` 分类选船，产出可替换的 `ship_sizes_top.dds` 与破损版；输出通道附带可直接粘贴的 `spriteTypes` 片段与 `icon =` 清单，让共用一个图标键的多艘船各自可寻址。
- 包体：全平台 universal VSIX（win-x64 ReadyToRun / linux-x64 / osx-x64 自包含服务端）。

## 验证契约

- `npm run build:docs`、`npm run compile`、`npm run check:release -- --skip-compile --skip-test` 均通过（两处 `package.json` 版本一致、NLS 同步、changelog 条目存在）。
- 全量单元测试 3105 passing；唯一失败是既有的 `promptBuilderSnapshot.test.ts`（explore 提示词断言，与本次改动无关，发布不阻塞）。
- GitHub Release `v2.33.0` 挂载 universal VSIX，发布说明取自 `release/CHANGELOG.md` 对应区块。
