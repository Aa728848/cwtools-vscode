# Agent Note: 发布 v2.32.0

Status: implemented

## 背景

自上个发布 v2.31.0（2026-10-15）以来共有 6 个提交，其中两个新特性与一个用户可见修复：
审批审阅模型可独立配置（`e2ee5966`）、无强制沙箱后端时的审批式降级（`b730e34c`）、
话题历史原子写入与读取保护（`e6f6810b`，修复「重启后已归档对话消失」）。

另外本次发布还承载了仓库从 fork 网络脱离后的首次发版（`94e4afd8` / `03419d8c`），
以及移除未被引用的 `release/.vsixmanifest`。

## 版本决策

- 两个 `feat` 提交均新增用户可见设置与行为 → 按 SemVer 定为**次版本 2.32.0**（2026-10-19）。
- 本次发布的首要目的不只是交付新特性：仓库重建后全部 Release 被清空，
  `client/extension/updateChecker.ts` 请求的 `/releases/latest` 一直返回 404，
  已安装用户的自动更新提示处于静默失效状态。发布后自动恢复，无需改代码。
- 设计决策归属各自 Owning Note（`architecture/2026-10-17-approval-reviewer-model-and-unsandboxed-review.md`、
  `architecture/2026-10-17-command-sandbox-degrade-with-consent-and-subagent-command-capability.md`、
  `bug-fix/2026-10-19-chat-topic-store-atomic-write-and-read-guard.md`），本篇只记录发布流程。
