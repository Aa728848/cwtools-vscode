# Agent Note: Release v2.39.0 —— Stellaris 4.6.0 正式版规则、块级废弃迁移警告与双向同步审计

Status: implemented

## Problem

自 `v2.38.1`（2026-11-22）发布以来，仓库完成了四组已验证迭代并需要向用户交付新版本：

1. **Stellaris 4.6.0（Corona Borealis）正式版规则全量同步**：涵盖测试版与正式版新增的完整意识形态子系统、巨构模块、100+ 命令/修正/作用域、149+ Common 字段、GUI 属性与 Shader ABI，以及 `trigger_docs.log` 分隔符与 `ideologies.cwt`/`country_types.cwt` 语法修复。
2. **F# 规则引擎与 CWT 废弃迁移警告闭环**：此前 `## error_if_only_match` 仅对叶子字段生效、不覆盖块字段，且补全仍会推荐过期旧键；31 个 Stellaris 4.x 引擎已移除或改名字段（如区划 `is_capped_by_modifier` → `is_uncapped`）缺少明确迁移警告。
3. **规则同步工具双向化**：新增 `interface/**/*.gui` 控件与外交/自定义事件窗口基线审计（`gui`）及反向陈旧字段审计（`stale-fields`），统一集成到 `report` HTML 报告。
4. **文档与测试基线维护**：仓库双语文档与代码注释精简同步，4.6.0 Shader 契约单测对齐最新审计计数。

## Decision

1. **版本定级（Minor `2.39.0`）**：本次包含 Stellaris 4.6.0 新大版本完整规则体系支持，以及语言服务器新增块级 `error_if_only_match` 校验与补全过滤能力，按 SemVer 升级次版本号为 `2.39.0`（2026-11-23），同步更新 `package.json` 与 `release/package.json`。
2. **三仓库严格分序提交**：先提交并推送 `submodules/cwtools`（`fef96655`）与 `submodules/cwtools-stellaris-config`（`5dda593`），再提交主仓库功能改动与子模块指针（`43b05d93`），最后以独立发布提交承载版本号、双语更新日志、本 Note 与 `package.ps1` 重新打包后的 `release/rules/stellaris-rules.zip` 及 `release/README.md`（如有变更）。
3. **全平台 Universal VSIX 打包与门禁前置**：在本地执行 `npm run build:docs`、`powershell -ExecutionPolicy Bypass -File ./package.ps1`（完整构建 win-x64 / linux-x64 / osx-x64 自包含 F# 服务端并生成 `release/foreverskywalker-stellaris-cwtools-2.39.0.vsix`）及 `npm run check:release -- --skip-compile --skip-test`，验证无误后再提交、打 `v2.39.0` 标签并推送触发 `.github/workflows/release.yml` 自动发布至 VS Code 市场与 GitHub Release。

## Alternatives considered

- **补丁版本 `2.38.2`**：不采纳。本次新增 Stellaris 4.6.0 大版本完整规则支持以及语言服务器块级废弃校验/补全过滤能力，超出补丁修复范畴。
- **跳过本地 `package.ps1` 直接推标签等 CI 构建**：不采纳。`release-extension` SOP 明确要求本地完成三平台服务端发布、Universal VSIX 打包与发布门禁验证后再打标签，提前暴露打包或依赖闭包问题。
- **使用 `package.ps1 -Publish` 本地直发**：不采纳。标准发布由标签触发 GitHub Actions Trusted Publishing（OIDC），统一交付 VS Code 市场与 GitHub Release。

## Consequences

- 用户侧：开箱支持 Stellaris 4.6.0 全量语法校验与补全；写入 `is_capped_by_modifier` 等 31 个 Stellaris 4.x 废弃字段时立刻收到黄色迁移提示，且补全列表不再推荐过期旧键。
- 发布侧：内嵌 `release/rules/stellaris-rules.zip` 与 `release/rules/stellaris-rules.version.json` 与 `submodules/cwtools-stellaris-config` (`5dda593`) 完全一致；推送 `main` 与 `v2.39.0` 后由 `.github/workflows/release.yml` 完成全平台构建、市场 Trusted Publishing 发布与 GitHub Release 创建。
- 本地发布验证：`npm run build:docs`、`powershell -ExecutionPolicy Bypass -File ./package.ps1`（win-x64 ReadyToRun、linux-x64、osx-x64 自包含服务端及 147.62 MB / 1,819 文件的 `foreverskywalker-stellaris-cwtools-2.39.0.vsix`）与 `npm run check:release -- --skip-compile --skip-test` 全部通过；F# 后端构建、`CWToolsTests` 废弃字段回归、`npm run test:fsx`（36/36）、`npm run test:rules-sync`（60 passing）、`shaderCwtContract.test.ts`（2 passing）与 `npm run typecheck:test` 全部通过。
