# AGENTS.md — Implemented Agent Notes

这些笔记记录已交付入库的决策事实。请严格遵循根目录 [AGENTS.md](../../../AGENTS.md) 与 [.agents/notes/README.md](../README.md)。

## 1. 保持交付态笔记与代码现实同步（Keep Current With Shipped Reality）

- `implemented/` 目录下的笔记必须以**现在时客观事实**描述系统现状。
- 当后续代码重构调整了文件路径、符号名称、配置键或默认值时，**必须在同一变更中原地修正受影响笔记中的事实陈述**（路径、命名、接口等），而非追加流水账修改记录。

## 2. 决策所有权（Owning Note）纪律

- **更新现有笔记优先**：如果已有笔记拥有该项决策，就地更新该笔记即满足变更纪律，严禁新建同质化重复笔记。
- **不得任意改写历史决策本身**：原地更新仅限于事实陈述的保鲜。如果业务发生了与历史决策相反的根本性反转，必须创建新 Note 并显式相互交叉链接（Cross-link）。
- **完全取代与合并（Consolidation）**：当新变动彻底淘汰旧特性、旧代码已无痕迹时，新 Note 可在完整吸收旧 Note 的独特经验、备选方案与验证契约后合并并归档旧笔记。
