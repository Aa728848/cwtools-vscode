# Agent Note: Release v2.21.0 for Chat LaTeX Math Formula Rendering, Next-Gen Models (GPT-6 & Mimo 2.6), and Stellaris v4.5 Rules Sync

Status: implemented

## Problem
自 `v2.20.0` 发布以来，项目在交互呈现、AI 模型生态扩展、游戏规则库同步以及计划执行稳定性方面完成了一系列演进与交付：
1. **聊天面板 LaTeX 数学公式渲染与排版**：设计并上线了纯前端、零外部重量依赖的 LaTeX 数学解析与渲染引擎（`client/webview/chat/math.ts`），支持行内 `$...$` 与独立块级 `$$...$$` 语法，支持分数、根号、上下标、希腊字母及缩放括号；通过专用排版样式与主题自适应渲染，大幅提升技术探讨与公式解释时的阅读体验；
2. **计划审批交接稳健性强化**：修复 `executePlanHandoff` 在处理 UTF-8 BOM 时的收据解析异常，去除非计划模式多余前置守卫，确保审批计划在跨会话流转与分叉时的原子稳定交付；
3. **GPT-6 旗舰系列模型接入**：全面引入 OpenAI GPT-6 家族（`gpt-6-sol`、`gpt-6-luna`、`gpt-6-astra`），配置了准确的上下文窗口、输出限制、思维链（Thinking）预算与计费数据，并扩展了 Codex OAuth 动态刷新流程；
4. **小米 Mimo 2.6 系列接入**：支持小米最新 Mimo 2.6 与 Turbo 系列模型（`mimo-v2-turbo`、`mimo-v2.6` 等），提供多样化推理与普惠模型支持；
5. **群星 Stellaris v4.5 规则库同步与自动化 SOP**：针对官方 v4.5 脚本更新同步最新 CWT 规则定义，更新 `cwtools-stellaris-config` 与 `cwtools-mcp` 子模块；沉淀并固化了 `stellaris-rules-sync` 技能规范，指导标准化同步作业；
6. **工程治理与文档标准对齐**：按照 DSH 标准体系规范了 Agent Notes 的分类归档标准，并修复了测试用例中的无用转义符以保证 CI 门禁全绿。

为了向用户交付上述数学公式渲染、模型生态支持与游戏规则库成果，依据 SemVer 规范，需将扩展升级为次版本 `2.21.0`，编写完整中英双语更新日志，编译构建跨平台自包含通用 VSIX 并上传发布至 GitHub Release。

## Decision
1. **版本号升级**：
   将根目录 `package.json` 与 `release/package.json` 的 `version` 统一升级为 `2.21.0`。
2. **更新日志编写**：
   在 `release/CHANGELOG.md` 中新增 `## [2.21.0] - 2026-09-23`，中英双语详尽记录 LaTeX 数学渲染、计划审批稳健性修复、GPT-6 与 Mimo 2.6 模型支持、Stellaris 4.5 规则同步以及工程治理修复。
3. **单源文档生成与发布门禁验证**：
   运行 `npm run build:docs` 同步生成发布用 `release/README.md`，运行 `npm run compile` 与 `npm run check:release` 确保门禁通过。
4. **跨平台 Universal VSIX 打包**：
   通过 `package.ps1` 依次编译跨平台自包含 F# 语言服务器（win-x64、linux-x64、osx-x64）、编译 TypeScript 客户端与 Rollup Webview，打成包含三平台的通用 Universal VSIX 包。
5. **Git 与 GitHub 发布**：
   暂存相关文件并提交，打上 `v2.21.0` 标签，推送至 GitHub 远端并使用 GitHub CLI 创建 Release 上传 VSIX 产物。

## Alternatives considered
- **升级为 2.20.1 补丁版本**：
   不采纳。本次新增了聊天公式渲染引擎、GPT-6/Mimo 2.6 新模型系列接入、规则库与自动化技能体系等多项全新特性与扩展，非纯向下兼容 Bug 修复，应遵循 SemVer 升级次版本（Minor Version）。
- **仅发布更新代码不打包上传 Release**：
   不采纳。用户明确要求根据 `release-extension/SKILL.md` 完成打包并上传本项目，需全流程闭环交付。

## Consequences
- 发布 `v2.21.0` 扩展包，全面覆盖三平台自包含运行环境。
- 模组开发者可在聊天面板查看优雅的 LaTeX 数学公式排版，调用 GPT-6 和 Mimo 2.6 系列前沿大模型，并享受与群星 v4.5 官方脚本完美匹配的 CWT 规则补全与校验。
