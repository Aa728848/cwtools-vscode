# Agent Note: Release v2.20.0 for Tool Presentation Modes (PTC/NATIVE), Lexical Type Erasure Engine, and Deterministic Mode Scheduling

Status: implemented

## Problem
自 `v2.19.0` 发布以来，仓库完成了 AI 运行时、代码沙箱执行、输入界面交互与任务调度层面的多项重磅特性与关键缺陷收敛：
1. **PTC 与 NATIVE 工具呈现分流机制**：设计并上线了 `ToolPresentationMode`（`'ptc' | 'native' | 'hybrid'`），支持用户配置与会话 Topic 生命周期持久化绑定；在 PTC 模式下大模型 API 载荷仅暴露唯一的 `run_code` 工具，原生工具全量收敛为沙箱内能力池，大幅削减 Schema Token 开销；将 `run_code` 加入必披露列表消除首轮冷启动死锁；
2. **子调用（Subcall）实时流式呈现**：沙箱内部调用的每个宿主工具均以独立 `subcall` 步骤实时透传至前端活动流水线，渲染 `<span class="codex-subcall-pill">PTC</span>` 微型徽标与双语执行计数，彻底消除了脚本执行期间的黑盒感与原始 JSON 暴露；
3. **输入栏与顶部栏交互重构**：废除输入框上方生硬的预选横条与顶部红色冲突徽标，将模式切换按钮以标准 30px 通用规格嵌入底部工具栏，实现像素级中轴基线对齐与全局下拉菜单互斥；
4. **纯分词词法感知 TypeScript 类型擦除引擎**：彻底替换易误伤代码的复杂正则匹配，构建了独立的 `typeErasure.ts` 分词引擎，杜绝字面量与注释误伤；彻底修复对象字面量布尔值（`{ isRegex: false }`）被误删导致 `ReferenceError: isRegex is not defined` 的严重缺陷；支持数值枚举常量求值与自引用、构造函数参数属性字段注入（`this.x = x`）、泛型与比较符消歧，并修复了宿主只读属性赋值报错；
5. **退役关键词自动路由与收敛计划审批边界**：彻底移除 `agentProfile.ts` 中的全部关键词正则路由，普通技术提问不再被误判为只读计划模式；任务模式完全收敛为用户显式置顶或 Agent 显式升级；同时严格收敛 `executePlanHandoff` 审批卡判定条件，杜绝长篇技术解答误弹审批卡；
6. **固化发布 SOP**：沉淀 `.agents/skills/release-extension/SKILL.md` 规范。

为了向用户正式交付上述重磅特性、沙箱稳定性突破与界面优化成果，根据语义化版本（SemVer）规范，需将扩展升级为次版本 `2.20.0`，编写完整的中英文更新日志，打包生成三平台通用 VSIX 并发布至 GitHub Release。

## Decision
1. **版本号提升**：
   将根目录 `package.json` 与 `release/package.json` 的 `version` 统一升级为 `2.20.0`。
2. **更新日志编写**：
   在 `release/CHANGELOG.md` 中新增 `## [2.20.0] - 2026-09-19`，中英双语详尽记录 PTC/NATIVE 工具呈现分流、子调用流式呈现、纯词法类型擦除引擎、沙箱加固、确定性任务调度及计划审批卡边界收敛。
3. **单源文档生成与发布门禁验证**：
   运行 `npm run build:docs` 同步生成发布用 `release/README.md`，运行 `npm run compile` 与 `npm run check:release` 确保门禁通过。
4. **编译构建与全平台打包**：
   通过 `package.ps1` 依次编译跨平台自包含 F# 语言服务器（win-x64、linux-x64、osx-x64）、编译 TypeScript 客户端与 Rollup Webview，打成包含三平台的通用 Universal VSIX 包。
5. **Git 与 GitHub 发布**：
   暂存相关文件并提交，打上 `v2.20.0` 标签，推送至 GitHub 远端并使用 GitHub CLI 创建 Release 上传 VSIX 产物。

## Alternatives considered
- **提升为 2.19.1 补丁版本**：
  不采纳。本次新增了 PTC/NATIVE 工具呈现分流系统、独立词法擦除引擎、全新底栏交互机制等多项重大特性与系统重构，非纯向下兼容的 Bug 修复，应提升次版本号（Minor Version）。
- **仅更新仓库代码不打三平台自包含包**：
  不采纳。用户依赖 GitHub Release 提供的自包含离线安装包（免装 .NET 运行时），必须完整构建三平台自包含二进制。

## Consequences
- 发布 `v2.20.0` 扩展包，全面覆盖三平台自包含运行环境。
- 用户可使用全新的 PTC 代码化工具调用模式，享受极致的 Schema Token 节省与实时子调用可视化流；沙箱代码执行与任务模式流转更加稳定、确定。
