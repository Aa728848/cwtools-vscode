# Agent Note: Release v2.19.0 for Agent Teams Peer Collaboration, Agent-Decided Task Mode, and Unified Multi-Agent Substrate

Status: implemented

## Problem
自 `v2.18.0` 发布以来，仓库完成了多项核心架构升级、重磅新特性研发与关键缺陷修复：
1. **Agent Teams 同行协作机制**：设计并上线了带冷启动唤醒的 `TeamMailbox` 邮箱系统、带 CAS 乐观锁与 `blockedBy` 依赖图分析的 `TeamTaskBoard` 并发任务看板、建议性文件写入范围锁定（advisory write scopes），以及配套的 7 项团队管理与通信工具；
2. **多智能体底座收敛与统一入口**：将原先分散的 DAG 波次执行平滑收敛到 Agent Teams 看板底座上，统一调度入口为 `dispatch_agents`，统一底层持久化为 `orchestration/<id>.json`，并将质量门禁（Quality Gate）抽象为跨 DAG 与 Teams 共享的代码审查与有界自动修复引擎；
3. **Agent 任务模式自主决策与用户置顶覆盖**：用 Agent 工具（`enter_plan_mode` / `exit_plan_mode`）取代了开销高昂且不确定的逐轮 LLM 语义意图分类器，支持模型自主决策规划升级并自动收缩写权限；提供 `/plan`、`/execute`、`/explore`、`/review` 及 `/mode` 等斜杠指令供用户置顶；将模式置顶与审批制品持久化到 `ChatTopic`，在跨话题、窗口重载和话题分叉时完整保留；
4. **本地化候选事务可达性与空事务支持**：修复了 `write_localisation` 未向 `CandidateTransactionManager` 注册导致纯本地化编辑无法进入暂存与验证的缺陷，并将传输故障与语法验证分离，允许空事务作为 no-op 安全提交；
5. **原版校验跳过设置与跨平台路径判定**：在 F# LSP 后端引入 `PathIdentity` 规范化比对，优化 `errors.vanilla` 与 `skip_validation` 规则，消除模组开发中的虚假原版警告。

为了向社区与用户正式交付上述重磅特性与架构成果，根据语义化版本（SemVer）规范，需将扩展升级为次版本 `2.19.0`，编写完整的中英文更新日志，打包生成三平台通用 VSIX 并发布至 GitHub Release。

## Decision
1. **版本号提升**：
   将根目录 `package.json` 与 `release/package.json` 的 `version` 统一升级为 `2.19.0`。
2. **更新日志编写**：
   在 `release/CHANGELOG.md` 中新增 `## [2.19.0] - 2026-09-18`，中英双语详尽记录 Agent Teams 同行协作、统一多智能体看板底座、Agent 自主任务模式与用户覆盖、本地化候选事务可达性修复及原版路径校验判定优化。
3. **单源文档生成与发布验证**：
   运行 `npm run build:docs` 同步生成发布用 `release/README.md`，运行 `npm run compile`、`npm run typecheck:test` 及 `npm run check:release` 确保门禁通过。
4. **编译构建与全平台打包**：
   通过 `package.ps1` 编译跨平台自包含 F# 语言服务器（win-x64、linux-x64、osx-x64）、编译 TypeScript 客户端与 Rollup Webview，打成包含三平台的通用 VSIX 包。
5. **Git 与 GitHub 发布**：
   提交更新 commit，打上 `v2.19.0` 标签，推送至 GitHub 远端并使用 GitHub CLI 创建 Release 上传 VSIX 产物。
6. **流程技能固化**：
   在 `.agents/skills/release-extension/SKILL.md` 中沉淀完整的发布 Skill 规范。

## Alternatives considered
- **提升为 2.18.1 补丁版本**：
  不采纳。本次新增了 Agent Teams 同行协作和 Agent 自主模式决策等重大功能及多项系统级重构，非纯补丁修复，必须提升次版本号（Minor Version）。
- **仅更新仓库代码不打三平台自包含包**：
  不采纳。用户依赖 GitHub Release 提供的自包含离线安装包（免装 .NET 运行时），必须完整构建三平台自包含二进制。

## Consequences
- 发布 `v2.19.0` 扩展包，全面覆盖三平台自包含运行环境。
- 用户可使用全新的 Agent Teams 同行协作和自主规划模式，并享有更高性能和更强韧性的多智能体开发体验。
