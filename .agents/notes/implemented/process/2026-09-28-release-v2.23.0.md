# Agent Note: Release v2.23.0 for Engine Cost Hover and Static Galaxy Edit Fix

Status: implemented

## Problem

自 `v2.22.1` 以来合入了四项面向用户的改动，需要走完整发布闭环交付：

1. **悬停不展示引擎实现**：悬停此前只展示规则能描述的语法（`##` 描述、作用域、本地化、事件目标）。但 mod 作者无法从语法看出 `has_tradition` 是 O(n) 而 `has_technology` 是 O(1)，也无法看出 `set_update_modifiers_batch`、`is_designable`、`has_any_flag` 这类反常识行为。本次为其补齐 **1248 / 1657** 条命令的引擎开销与硬编码行为标注。
2. **静态银河新增连线的 ID 引号形式与标本规则误报**：新增 Hyperlane 写出裸整数与 vanilla 风格不一致；`specimens.cwt` 的 `resources.category` 缺 cardinality 导致原版标本文件 64 条 CW242 误报。
3. **文档可选字段自动探测**：`num_pops_assigned_to_job.pop_group` 等被文档标注可选却仍是必填，新增自动探测取代人工穷举。
4. **内置 Stellaris 规则包需要同步**：`release/rules/stellaris-rules.zip` 需从 `submodules/cwtools-stellaris-config` 重新打包，并同步 `submodules/cwtools` / `cwtools-stellaris-config` 指针。

第 1、2 项均包含**新增用户可见能力**（悬停新区块、自动探测命令），依据 SemVer 应升级次版本 `2.23.0`。

## Decision

1. **版本号升级（Minor）**：
   将根目录 `package.json` 与 `release/package.json` 的 `version` 统一升级为 `2.23.0`。
2. **更新日志编写**：
   在 `release/CHANGELOG.md` 顶部新增 `## [2.23.0] - 2026-09-28` 区块，按既有中英双语格式记录引擎开销悬停（特性）、静态银河引号与标本误报修复（修复）、内置规则包同步（维护）。原 `[Unreleased]` 区块的内容并入本次发布，不再保留空的 Unreleased 段。
3. **单源文档与门禁**：
   运行 `npm run build:docs` 同步 `release/README.md`，运行 `npm run compile` 与 `npm run check:release -- --skip-compile --skip-test` 验证版本一致性、NLS 完整性、文档单源约束与平台产物存在性。
4. **跨平台通用 VSIX 打包**：
   执行根目录 `package.ps1`，依次发布 win-x64（ReadyToRun）、linux-x64、osx-x64 自包含 F# 语言服务器，重新压缩内置规则包（从子模块 HEAD 读取 commit 与时间戳写入 `stellaris-rules.version.json`），编译 TypeScript 客户端与 Rollup Webview，最终由 `@vscode/vsce` 输出单一通用 `.vsix`。
5. **Git 与 GitHub 发布**：
   提交版本与日志变更，打 `v2.23.0` 标签，推送分支与标签，并通过 GitHub CLI 创建 Release 并挂载 VSIX 产物。

## Alternatives considered

- **升级为补丁版本 `2.22.2`**：不采纳。悬停的引擎开销区块与文档可选字段自动探测都是**新增的用户可见能力**（新指令、新输出、新审计命令），不是既有行为的缺陷修复，按 SemVer 属于次版本升级。
- **把引擎开销事实硬编码在 F# 后端**：不采纳。开销等级是随游戏版本变化的**规则内容**，硬编码会导致每次版本更新都要改代码发版，规则维护者也无法参与；已改为 `## cost` / `## engine` / `## engine_evidence` 三个 CWT 指令。
- **为剩余 409 条命令补全标注**：不采纳。这些命令在反编译结果中无法链接到命名实现类（注册虚表不含类名），猜测一个等级会向用户输出错误结论，留白更诚实。悬停对未标注命令不显示该区块。
- **规则子模块变更与扩展发版分离**：不采纳。内置规则包随 VSIX 分发（`release/rules/stellaris-rules.zip`），子模块指针与规则包必须在同一次发版中一起交付，否则用户拿到的校验行为与声明版本不一致。

## Consequences

- 发布 `v2.23.0` 通用扩展包，覆盖 Windows / Linux / macOS 自包含运行环境。
- Stellaris 悬停对 1248 条命令额外给出引擎开销类别、硬编码行为说明，以及已确认时的引擎函数与 dump 行号；新增事实只需改 CWT 规则，无需改代码或发版。
- 静态银河预览新增连线与 vanilla 风格一致；原版标本文件不再产生 CW242。
- 内置规则包与 `cwtools` / `cwtools-stellaris-config` 子模块指针保持一致；`stellaris-rules.version.json` 记录打包来源 commit `9ca5967`。
- 已知局限：复杂度等级是实现形态的推断而非基准测试；调用深度 1 之外若有扫描会被漏判为 O(1)（实测该比例约 35%），故 "O(1)" 取保守定义——命令及其直接调用者均无循环。
- 版本号仅由根 `package.json` 与 `release/package.json` 承载，文档与注释不重复数字，遵循既有约定。
