# Agent Note: Release v2.34.1 for Validation Allocation Reduction and Stellaris 4.5.3 Rules Sync

Status: implemented

## Problem

自 `v2.34.0`（2026-10-27）发布以来，主分支合入了两组面向用户的质量与规则更新：

1. **校验热路径重复计算与服务重建分配收敛**（`5bfe4c32`，`submodules/cwtools` `559f4f24`）：普通 `type[...]` 键语义变更升级为增量服务重建后，重复校验与全表预热仍带来可观的中间对象分配；通过在 `cwtools` 子模块引入有界规则校验结果记忆化、动态校验器工作区快照按纪元复用、服务输入按不可变源引用缓存、staged processed-localisation 候选三层守卫发布以及 `forceRecompute` 仅替换已建 `Lazy`，在不改变任何公开诊断结果的前提下降低累计分配。
2. **Stellaris 4.5.3 规则同步与命令块参数漂移校对**（`9535cd61`、`082cf0ae`、`83c307e0`、`d9c5623d`、`3d43642a`，`submodules/cwtools-stellaris-config` `1aba83ae`、`submodules/cwtools-mcp` `57116f4`）：同步 Stellaris 4.5.3 作用域契约与 Shader ABI 目录，为 `tools/rules-sync/report.ts` 补齐命令块参数键漂移检测（支持同行并列花括号组取并集），并校对补齐 `transfer_pop_amount.keep_automodding`、`total_system_workforce_with_job_tag.limit`、`create_country.ruler` 与 `flag.use_ship_color` 等规则字段。

上述改动属于向下兼容的性能优化、规则缺陷修复与版本规则同步，未新增扩展命令、配置项或公开协议契约，需按补丁版本发布并同步刷新随包分发的 `release/rules/stellaris-rules.zip`。

## Decision

1. **版本定级（Patch `2.34.1`）**：
   依据 SemVer 与仓库既有补丁发布惯例（参见 [2026-09-25-release-v2.22.1.md](2026-09-25-release-v2.22.1.md)），将根目录 `package.json` 与 `release/package.json` 的 `version` 从 `2.34.0` 升级为 `2.34.1`（2026-11-06）。
2. **更新日志与技术决策归属**：
   在 `release/CHANGELOG.md` 顶部新增 `## [2.34.1] - 2026-11-06` 双语条目；底层技术设计与取舍分别归属既有 Owning Note [2026-10-14-incremental-type-definition-fanout-and-scripted-services-escalation.md](../bug-fix/2026-10-14-incremental-type-definition-fanout-and-scripted-services-escalation.md)（Decision 11）与 [2026-09-23-stellaris-v4.5-rules-sync-and-cwt-updates.md](../feature/2026-09-23-stellaris-v4.5-rules-sync-and-cwt-updates.md)，本篇仅记录发布流程决策。
3. **单源文档、内置规则包与全平台 VSIX 构建**：
   运行 `npm run build:docs`、`npm run compile` 与 `npm run check:release -- --skip-compile --skip-test`，随后执行 `package.ps1` 依次编译 win-x64（ReadyToRun）、linux-x64、osx-x64 自包含 F# 语言服务器，从 `submodules/cwtools-stellaris-config` `1aba83ae` 重新打包 `release/rules/stellaris-rules.zip` 与 `.version.json`，并生成通用 VSIX 安装包。
4. **Git 标签与 GitHub Release 交付**：
   将版本号、CHANGELOG、发版 Agent Note 与更新后的内置规则包一并提交，创建 `v2.34.1` 标签推送至远端，并通过 `gh release create` 发布挂载 VSIX 的 GitHub Release。

## Alternatives considered

- **升级为次版本 `2.35.0`**：
  不采纳。本次包含的 `feat(rules-sync)` 仅作用于仓库内部维护脚本 `tools/rules-sync/report.ts`，对扩展终端用户而言交付的是校验器内存分配优化与 Stellaris 4.5.3 规则/参数同步，无新增命令、设置或诊断码，按 SemVer 应定为补丁版本 `2.34.1`。
- **仅更新子模块指针而不重打扩展 Release**：
  不采纳。扩展运行时使用的内置规则包 `release/rules/stellaris-rules.zip` 与三平台自包含 `.NET` 服务端二进制均随 VSIX 分发，不发版则终端用户无法获得 `cwtools` `559f4f24` 的校验性能改进与 `1aba83ae` 的 4.5.3 规则修复。

## Consequences

- 交付 `v2.34.1` 全平台通用 VSIX，Windows / Linux / macOS 服务端二进制均升级至包含规则校验记忆化与分配优化的 `cwtools` `559f4f24`。
- 内置规则包 `release/rules/stellaris-rules.zip` 及 `stellaris-rules.version.json` 同步锚定至 `cwtools-stellaris-config` `1aba83ae`（Stellaris 4.5.3），消除 `total_system_workforce_with_job_tag.limit`、`transfer_pop_amount.keep_automodding`、`create_country.ruler` 等写法的误报。
